# Learning Resources

## Repository sources

- `README.md` — setup, architecture, API surface, security and privacy claims.
- `docs/PRD.md` — requirements, design decisions, acceptance criteria, and out-of-scope items.
- `docs/PROJECT_WORKING_DOCUMENT.md` — conceptual architecture and user journeys.
- `LEDGERLY_INTERVIEW_NOTES.md` — existing interview-oriented explanations to verify and improve.
- `graphify-out/GRAPH_REPORT.md` — generated structural map of files, modules, and communities.
- `apps/backend/src/index.ts` — backend route and middleware composition.
- `apps/backend/prisma/schema.prisma` — database model and relationships.
- `packages/shared/src/transaction-extractor.ts` — deterministic parsing engine.
- `packages/shared/src/contracts.ts` and `csv.ts` — validation and import normalization.

## External concepts to learn

- HTTP and REST request/response contracts
- React and Next.js App Router boundaries
- TypeScript types versus runtime validation
- Authentication, authorization, sessions, bearer tokens, and JWTs
- Multi-tenancy and defense-in-depth isolation
- PostgreSQL, indexes, transactions, and row-level security
- Prisma ORM and migrations
- deterministic parsing, confidence scoring, and duplicate detection
- TanStack Query server state and cache invalidation
- cursor pagination and optimistic/concurrency-safe updates
- unit, integration, and end-to-end testing
