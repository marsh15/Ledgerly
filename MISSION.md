# Ledgerly Interview Learning Mission

## Why I am learning this

I vibecoded Ledgerly and need to understand the entire project deeply enough to explain the assignment honestly, walk through the important code paths, answer prerequisite questions, defend design decisions, and identify limitations and production improvements in an interview.

## Target capability

I should be able to explain Ledgerly from browser request to database row and back, including authentication, tenant isolation, validation, deterministic parsing, CSV imports, CRUD, pagination, analytics, subscriptions, AI privacy boundaries, frontend state management, testing, and deployment. I should be able to trace unfamiliar files instead of memorizing isolated summaries.

## Teaching preferences

- Explain concepts from first principles, then tie them to Ledgerly.
- Use the actual files and line-level code behavior.
- Prefer detailed mental models, examples, tradeoffs, and honest limitations over slogans.
- Use retrieval questions and small walkthrough exercises to check understanding.
- Build interview answers only after the underlying concepts are understood.
